# NexLink — system back navigation

Добавлена поддержка системной кнопки «Назад» на Android/iOS через History API.

Поведение:
- просмотр профиля/панели → закрывает панель;
- встроенный браузер → закрывается;
- просмотр медиа → закрывается;
- открытый чат → возвращает к списку чатов;
- контакты/настройки → возвращают во вкладку чатов;
- состояние URL не меняется, используется только history state.


## Текущие ограничения интерфейса

- На телефонах контекстное меню вызывается долгим нажатием (~0,5 с) на чате или сообщении; обычный тап сохраняет своё основное действие.
- Для телефонов включён отдельный mobile-ui слой с touch-оптимизированными размерами, safe-area и мобильным контекстным меню.
- Dev/Developer Console убран из пользовательских настроек.
- Встроенный браузер убран; ссылки открываются во внешнем браузере устройства.
- Голосовые сообщения временно отключены для отправки и воспроизведения.
- NexLink Security работает только как системный бот уведомлений. Пользовательские сообщения в его чат отклоняются и на уровне API-клиента.
