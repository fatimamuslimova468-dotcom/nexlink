# NexLink — system back navigation

Добавлена поддержка системной кнопки «Назад» на Android/iOS через History API.

Поведение:
- просмотр профиля/панели → закрывает панель;
- встроенный браузер → закрывается;
- просмотр медиа → закрывается;
- открытый чат → возвращает к списку чатов;
- контакты/настройки → возвращают во вкладку чатов;
- состояние URL не меняется, используется только history state.
