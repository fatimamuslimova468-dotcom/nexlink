# NexLink: Firebase авторизация и 2FA

Для входа по email/паролю Firebase должен разрешать провайдер **Email/Password**.

В Firebase Console откройте:

`Authentication → Sign-in method → Email/Password`

и включите провайдер.

Для двухэтапной проверки в этом проекте используется Firebase Auth TOTP MFA. Пользователь сначала входит по email/паролю, после чего Firebase запрашивает 6-значный код TOTP. В настройках NexLink переключатель «Двухэтапная проверка» теперь синхронизируется с фактическим `multiFactor.enrolledFactors`, чтобы состояние не расходилось.


Раздел **«Память и данные»** очищает локальный браузерный кэш и локальные стикеры. Медиа и сообщения, сохранённые в Firebase, удаляются с сервера только отдельными функциями удаления и этой кнопкой не затрагиваются.
